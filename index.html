Sobre mim

Olá! Meu nome é Carlos Eduardo Anequini e sou estudante de Engenharia de Software, em transição de carreira para a área de tecnologia. Tenho como objetivo atuar como Desenvolvedor Full Stack, unindo conhecimentos de desenvolvimento Front-End e Back-End para criar aplicações completas, funcionais e eficientes.

Minha formação e meus estudos envolvem tecnologias como HTML5, CSS3, JavaScript, React, Node.js, APIs REST, bancos de dados SQL e NoSQL, além de Git e GitHub para versionamento e gerenciamento de projetos. Também possuo conhecimentos em lógica de programação e Python, que contribuem para minha base de desenvolvimento.

No Front-End, busco desenvolver interfaces responsivas, acessíveis e com boa experiência de usuário. No Back-End, trabalho com a construção de APIs, regras de negócio, integração com bancos de dados e comunicação entre diferentes serviços.

Minha experiência profissional anterior na área de manutenção industrial contribuiu para desenvolver habilidades como raciocínio lógico, resolução de problemas, análise, organização e atenção aos detalhes, competências que hoje aplico no aprendizado e desenvolvimento de software.

Atualmente, estou focado em aprimorar continuamente minhas habilidades, desenvolver projetos práticos e construir um portfólio que demonstre minha evolução como desenvolvedor. Meu objetivo é conquistar uma oportunidade na área de tecnologia, contribuir com projetos reais e continuar crescendo profissionalmente como Desenvolvedor Full Stack.
